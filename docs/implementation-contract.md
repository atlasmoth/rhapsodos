# Native integration contract

The shared `ReaderCore` is the canonical synchronous store. Native adapters call it from their existing serialized repository and decode JSON with unknown-key tolerance. Native files, audio transport, downloads and inference remain platform owned. These signatures are the implementation contract for the current build.

## Library and source

Canonical playback cursors include `passageFraction` in `0...1`, alongside passage identity and native `offsetMillis`. `saveProgress(documentId,passageId,offsetMillis,passageFraction)` rejects non-finite or out-of-range fractions. Migration `4.sqm` advances SQLite schema version 4 to 5, retaining existing user data and giving retained cursors a fraction of zero. Portable archives carry the fraction; earlier archives restore with zero when it is absent. Migration `5.sqm` advances schema 5 to 6 by dropping the removed bookmark table; documents, notes, edits, recordings and playback cursors remain intact. Migration `6.sqm` advances schema 6 to 7 by dropping custom pronunciation rules and their narration revision table. Plain whitespace normalization regenerates spoken text without changing source or note anchors. For documents with removed corrections, migration clears the obsolete playback audio offset but retains the passage and source fraction; native transports resolve that fraction against the new audio duration. Uncorrected-document cursors and all note offsets remain unchanged. Restore ignores obsolete bookmark and pronunciation fields in existing archives.

`DocumentRecord.listeningProgress` is derived from the canonical source cursor, weighted by cumulative UTF-16 source ranges. It is `null` during preparation, zero before listening, and reaches one only when the last passage is saved at completion. Native audio supplies the measured within-passage fraction. Note-replay clocks never write reading progress. This is source progress, not a fabricated full-file audio duration or a replacement note anchor.

`resolveSourceSeekJson(documentId,sourceRevision,fraction)` validates a finite whole-document fraction, the current source revision and a finalized nonempty graph, then returns a read-only `SourceSeekTarget`. Exact one resolves to the final passage at one; an omitted separator or passage boundary resolves forward to the next passage at zero. Native owners accept this target only for the same current session after asynchronous resolution, commit one seek at drag release, preserve play intent for interior targets and leave the exact endpoint paused. Source-proportional audio seeking declares passage-level precision. Recording and note replay disable book seeking and retain the book cursor.

- `beginDocument(id,title,filePath,pageCount)` creates a preparing document. `appendDocumentPages(documentId,pagesJson,finished)` accepts ordered contiguous new pages, preserving all earlier text and offsets. Finalization requires the declared page count. Both return the current document snapshot; native UI can listen to already prepared passages while preparation continues.
- `updatePageGeometry(documentId,pageIndex,regionsJson,geometrySpace)` validates and replaces only a prepared page's geometry and returns its document snapshot. The native caller must freshly prepare the same original page and prove complete canonical text equality before calling. Embedded text may match the complete raw page or the complete raw page trimmed only at outer whitespace, with an explicit literal UTF-16 prefix offset applied to every region. OCR requires exact whole-page equality. Substring, fuzzy and internal-whitespace matching are excluded. Shared validation checks page-relative UTF-16 ranges and normalized bounds. Source text/revision, passages, notes and progress remain unchanged.

- `searchJson(documentId,query)` returns up to 100 `{kind,id,documentId,passageId,title,text,pageIndex}`. Empty document ID searches the library. Search is literal and local.
- `renameDocument(documentId,title)` updates the canonical title.
- `deleteDocumentJson(documentId)` and `deleteNoteJson(noteId)` return `{paths:[...]}`. Stop playback/capture for the affected document before invoking deletion. Files become pending garbage in the same transaction; native adapters remove only owned files and call `acknowledgeFileRemoval(path)` after successful removal. `pendingFileRemovalsJson()` recovers cleanup after a crash. Never delete a current recording.
- `exportDocumentJson(documentId)` returns one read-only canonical `DocumentArchive` snapshot under the store lock. The manifest uses `rhapsodos-document`, format version `1`, and contains `document`, `pages`, saved `notes`, `position` and `sections`; removed bookmark/pronunciation fields are not emitted. Export requires finalized complete pages, a source graph matching those pages, valid note attachments and bounded sections/progress. Unsaved recording drafts and interrupted drafts block export. Untagged geometry is omitted from the export copy without altering source rows or anchors. Native owners freeze listening progress before calling, verify/copy the original PDF and every committed recording, rewrite file locators to portable relative asset paths and publish a complete archive only after durable file completion. Generated narration and downloadable models are excluded. Export is reached through Settings and does not upload anything automatically.
- `restoreDocumentJson(archiveJson)` atomically validates and restores the manifest into a vacant document ID. Native importers copy/verify owned files first and replace manifest file locators before calling this method. A collision is rejected without replacing existing data. Portable archives use relative asset paths; existing user archives remain supported. Imported playback retains its passage/source fraction and clears the foreign audio offset because the receiving narration edition may differ; all note offsets remain intact.

`SourcePage` includes `provenance` (`embedded` or `ocr`), `languageTag` (default `en`), `geometrySpace` and `regions`, an array of `{start,end,x,y,width,height}`. Region ranges are page UTF-16 offsets. The supported tag `cropTopLeftV1` means normalized top-left coordinates in the **unrotated PDF crop box**; native rendering applies the original page's rotation. Nonempty geometry requires that explicit tag on new pages and archive restore. Untagged stored rows read as `unspecified` and cannot supply a painted/hit target until exact-text geometry repair succeeds. Embedded PDF selection and OCR regions are different geometries. `Passage` includes `displayText`, `languageTag`, `mappingVersion`, `spokenMapping` with `{spokenStart,spokenEnd,sourceStart,sourceEnd}` page-relative ranges, and `provenance`. `documentJson` includes `pages` and page-based `sections` with `{id,title,passageId,pageIndex}`. Do not fabricate heading detection.


Mapping intervals include `kind` (`linear`, `collapsed`, `replacement`). Linear intervals with equal source/spoken lengths interpolate an intersecting spoken subrange to obtain its exact source subrange. Other intervals map to the whole source interval. Adjacent linear intervals are coalesced to keep ordinary documents compact; an interval is not a word boundary. `mappingVersion` is `whitespace-v1` for the current source-preserving whitespace transform.

## Anchored notes

- `createNoteDraft(noteId,documentId,passageId,recordingPath,offsetMillis)` freezes the source attachment and returns its canonical record. Pause native transport before calling it. The native offset supplements the passage's source revision/ranges and quote; it does not replace them. A double-tapped passage away from current narration uses offset zero. Its attachment is independent of the frozen book cursor, which save/resume retains.
- `commitNote(noteId,recordingPath,durationMillis)` accepts durable nonempty audio and returns the saved record. Repeating the same commit is idempotent; a saved recording's locator and duration are immutable.
- `saveTextNote(noteId,documentId,passageId,text,offsetMillis)` saves a typed thought without audio. Reusing its ID is idempotent only for the same attachment and text. Use `editTranscript(noteId,text)` for deliberate edits.
- `markNoteStatus(noteId,status)` accepts `interrupted` only for an unsaved zero-duration draft. Saved recordings cannot become interrupted drafts. Transcription states (`pending`, `pendingModel`, `transcribing`, `transcribed`, `failed`) require committed audio.
- `updateTranscript(noteId,text,status)` records machine output without replacing a manual edit. It accepts `transcribed`, `failed` and `pendingModel` after audio commit.
- `discardDraft(noteId)` removes only an unsaved draft. Native code must successfully remove its owned recording before acknowledging the discard; file failure leaves a visible retryable draft.

Saving or recovering audio does not depend on ASR. Native adapters finalize and synchronize audio before canonical commit, preserve original recovery data, and keep post-commit presentation failures from changing the saved note's status or attachment.

## Outline

- `setDocumentSections(documentId,sectionsJson)` accepts a bounded array of genuine PDF outline destinations resolved to prepared passage IDs. Each section is `{id,title,passageId,pageIndex}`. Store the original PDF's outline, not guessed headings. If no outline is available, page sections remain a truthful fallback. Returns the document snapshot.

## Downloadable speech

- `modelCatalogJson(platform)` returns the bundled or accepted curated entries: `{id,name,capability,platform,runtime,adapter,version,languageTags,minimumOS,minimumMemoryMB,license,licenseUrl,description,files:[{path,url,sha256,bytes}],totalBytes}`. `adapter` selects an existing compiled speech profile and defaults to the bundled pack ID. Native adapters enforce OS, storage and memory compatibility before recommending an entry. Qualification is separate from compatibility.
- `modelCatalogStatusJson()` returns `{revision,acceptedAt,source}`; bundled status has revision/acceptedAt zero. Migration `7.sqm` adds the catalogue row without modifying existing user or installation records.
- `acceptModelCatalogJson(payloadJson)` accepts only an exact UTF-8 payload already authenticated by native P-256/SHA-256 verification. It validates format, publication, optional expiry, revision, immutable identities, supported profiles and bounded pinned assets before atomic persistence. Omitted or null `expiresAt` means permanent; publication tooling omits it. Exact semantic repeats return false without writes. Omitted installed/in-flight editions remain discoverable while their adapter is supported. Cached entries for removed adapters are excluded; their native owners clean up model assets and inventory without touching user data. Newly bundled profiles also remain visible alongside an older cached catalogue, without altering its signed payload or existing edition identities. The four supported profiles are Phonon CPU/CoreML narration and Moonshine/Whisper transcription; its CoreML release ZIP is accepted only as the exact compiled descriptor, or as a compatible new edition at a pinned-revision URL. Native clients serialize acceptance against active downloads, capture, narration and inference. HTTPS configuration and public trust key live in `ModelCatalogSource`; no release endpoint is configured yet. See [model-manager.md](model-manager.md) for the envelope and publication workflow.
- `modelInstallsJson()` returns `{packId,generation,status,bytesDownloaded,totalBytes,installedPath,error,updatedAt}` records.
- `beginModelInstall(packId,generation)` starts an absent pack or restarts a paused/failed attempt and returns its record. It rejects a currently ready pack; this API does not perform live ready-pack upgrades. Retained failed-install files can be verified, repaired or removed. The generation is a fresh native UUID per attempt.
- `updateModelInstall(packId,generation,status,bytesDownloaded,error)` accepts `downloading`, `paused`, `verifying`, `failed`. Stale callbacks are ignored. Status must never claim readiness.
- `activateModel(packId,generation,installedPath,verifiedFilesJson)` accepts an owned relative path `Models/<packId>/<version>` and the complete array of `{path,sha256,bytes}` matching the pinned catalog. Native code hashes every file, fsyncs and moves the staging directory atomically, and performs a runtime smoke check before activation. Only then does the canonical record become `ready`.
- `removeModel(packId)` removes inventory only after native code reserves removal, cancels/joins dependent work, unloads the runtime, removes every owned version/staging file and synchronizes the parent directories. A cleanup failure retains visible inventory for retry and keeps the pack unavailable to inference. This never removes recordings or notes.
- `invalidateModel(packId,generation,error)` marks a matching ready installation failed after missing/corrupt-file detection. A stale check cannot invalidate a newer installation. The files remain available for native repair/cleanup, but failed packs cannot be selected; retry uses a new generation. Never send a recording to a fallback when an installed pack breaks.

HTTPS GET requests are restricted to catalog assets and their audited CDN redirects. Range resumption verifies byte counts and hashes; rejected ranges restart the individual staging file. No document text, recording, transcript or filename belongs in a request, diagnostic or URL. Downloads are explicit, cancelable and resumable. Runtime libraries must receive local paths with their automatic download behavior disabled. A downloaded pack only becomes selectable after successful validation.

Transfers may continue while the app is inactive. Expensive runtime checks wait for the foreground and an idle listening/capture workload; completion of transferred bytes does not promise immediate offline readiness in a closed app.

Both apps use `com.osuji.ereaderapp`, version `0.01`, build `1`, and the display name **Rhapsodos**.
